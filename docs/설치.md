# 설치와 실행

Node.js 22 LTS 최신 패치와 npm을 준비합니다. Windows 터미널에서는 필요하면 `npm` 대신 `npm.cmd`를 사용합니다.

## 서버

저장소 루트에서 `npm ci` 후 `npm run server`를 실행하고 `http://localhost:3000`을 엽니다. 기본 DB는 `data/messenger.db`에 생성됩니다. 빈 환경에서는 웹에서 계정을 새로 만듭니다. 실제 비밀번호·토큰·DB·설정 파일은 저장소에 추가하지 않습니다.

다른 주소·DB가 필요하면 서버의 `PORT`, `DB_PATH` 환경 변수를 지정합니다. Docker가 설치되어 있으면 `docker compose up --build -d`로 실행할 수 있습니다. Docker 데이터는 `./data`에 보존됩니다. 공개 소스에는 데스크톱 설치 파일이 없으며 운영자가 별도로 빌드해 배치합니다.

## 내 에이전트 연결

사용할 Claude Code 또는 Codex CLI를 PC에 설치하고 로그인합니다. 웹의 가입·로그인 후 본인의 데몬 토큰을 확인한 다음 실행합니다.

```sh
npm run doctor
npm run setup
npm run daemon
```

같은 PC의 기본 서버 주소는 `http://localhost:3000`입니다. 다른 PC에서 연결하려면 운영자의 서버 주소를 입력합니다. 설정은 기본적으로 사용자 홈의 `.agent-messenger/config.json`에 저장됩니다. 작업 폴더에는 공유하려는 프로젝트만 지정합니다. 작업 폴더 밖 자료·인증 파일은 접근 정책으로 제한되며, 파일 변경은 소유자의 별도 1회 승인이 필요합니다.

## 검사

```sh
npm run desktop:build
npm test
npm run package:daemon
```

macOS·Linux 빌드는 `clang`이 필요합니다. 자동 검사는 실제 AI 응답과 각 운영체제의 설치·알림 화면을 보증하지 않습니다. 데스크톱 빌드는 [별도 안내](../desktop/README.md)를 참고하세요.
